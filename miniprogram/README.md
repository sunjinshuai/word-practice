# 微信原生单词练习簿

使用 WXML、WXSS、JavaScript 和微信原生 API，独立于现有 React 网页。没有 web-view、React 或跨端框架依赖。

## 导入与试用

1. 安装微信开发者工具，选择“导入项目”，目录选择当前 `miniprogram` 文件夹。
2. 使用自己的微信小程序 AppID。工程目前填写 `touristappid`，仅用于无 AppID 的本地尝试；上传及真机预览需要正式 AppID。无需在聊天或代码中提供 AppSecret。
3. 选择普通小程序、JavaScript 编译，在开发者工具中编译。建议使用较新的稳定基础库，并启用 ES6 转 ES5、增强编译。
4. 点击“开始练习”，检查手机键盘输入、删除、音频及下一题。音频已打包，不需要配置下载域名。
5. 正式发布需在微信公众平台完成个人主体小程序相关信息、备案和隐私说明，再上传体验版、审核并发布。提交前以后台实际要求为准。

## 功能与结构

- U1–U3，共 158 题；按单元与页码/主题/语法选择范围。
- 随机、间隔复习及错题练习；10/20/全部；英汉两个方向。
- 英文按字母展示，使用一个原生输入控件接收当前单词，支持完整词输入、删除与粘贴。每个词拼对才进入短语中的下一个词；错误下划线变红，光标留在末尾。
- 整题答对停留，随机颜色的词性标签、粒子动画、完整朗读一次；点击“下一题”切换并朗读。粒子层不拦截点击。
- 朗读使用既有 Aria 合成音频，158 条完整题目音频转换为本地 AAC；输入、删除、错误提示音独立。朗读前停止上次播放。
- 进度、正确率、错题本、复习时间表、每轮记录及逐题明细。第一次答错后修正不会重复计分。
- 拼读参考沿用网页版：元音字母标注、手动试切、参考切分核对。音节切分是教学辅助，不等同于自动生成准确音标。

`components/` 负责设置、字母格、粒子及拼读界面；`pages/` 负责流程与历史页面；`domain/` 负责题目判定、复习和拼读；`services/` 封装音频和记录；`data/` 保存词库。

## 记录保存边界

使用微信本地存储，不需要小朋友登录邮箱，不接入付费服务。记录保存在当前微信设备，清理小程序数据可能丢失；暂不跨设备同步。网页版原有记录不会自动迁移。保存失败会在页面提示，内存记录继续保留至应用关闭。后续云数据库可以接在独立的记录服务层。

## 已执行验证与待验收

运行 `npm test` 和 `npm run check`（仅测试需要 Node.js）。覆盖错误拦截、粘贴、删除、手动下一题、首错统计、中文模式、存储失败和音频停止；检查文件引用、语法、158 条音频覆盖及主包体积。音频主包约 1.8 MB（未经过微信压缩）。
