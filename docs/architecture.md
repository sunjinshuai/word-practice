# React 重写结构

## 数据流

App 组合 useLearning、useAudio、usePractice，并将当前练习及回调传给组件。设置弹框使用独立草稿，确认才开始新一轮；切换单元清空学习范围。

usePractice 管理题队列、索引、首次判分和订正状态。LetterSlots 管理当前题的字母及逐词锁定，通过回调通知判分，不读写数据库。答对和订正后留在原题；下一题是显式动作。

domain 的判题和复习安排均为纯函数。首次错误即记录，重复输入及订正不再新增首次判分。历史记录由事件生成，保持原题目 ID 和 v1 数据库结构。数据库初始化完成前禁止开始，防止历史加载覆盖新作答。存储失败显示仅本次有效。

音频服务持有唯一播放器，开始新播放前停止旧播放。hook 管理静音和状态，退出时销毁播放器及提示音上下文。粒子组件的 effect 负责创建和取消动画，切题或卸载立即清理，粒子不接受指针事件。

## 边界

词库与音频映射集中维护；组件不包含数据副本。IndexedDB、音频和 WebView 视口分别隔离；后续接入远程存储或其他声音可替换服务层。没有引入全局状态库、路由库或 UI 组件库，小型单页用 React 状态即可。

样式沿用原有 CSS，避免重写技术栈同时更改视觉设计。焦点、dialog 和 Web Animations 使用 ref 与 effect，是 React 生命周期内的浏览器能力调用。

## 发布

Vite 生成 dist，相对 base 支持子路径。音频作为 public 静态资产复制，不在运行时请求 TTS。GitHub Pages 工作流执行单元测试和构建；浏览器回归在本地 Chrome 执行。切换发布方式和 push 仍是单独的发布操作。
