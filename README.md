# 单词练习簿

适合五年级及初中学生的中文界面英语默写网站，包含 5A U1–U3 共 158 项单词、短语和句子。

## 启动

在项目目录运行：

```sh
python3 -m http.server 8765
```

浏览器访问 http://localhost:8765/ 。项目是静态网页，无需安装前端依赖。

## 功能

- 单元、练习方式、默写方向和题量选择。
- 本轮进度条：显示已完成题数和百分比，订正完成后推进。
- 逐字母输入；每个单词填完自动批改，拼错后先订正再继续。答对后展示逐词词性并完整朗读一次，手动点击下一题。
- 错误下划线、答题动效、输入及删除提示音。
- 错题本、正确率统计、浏览器本地保存的间隔复习计划。
- Aria 美式神经语音：开始及切题自动完整朗读一次；356 段 MP3 保存在 audio/，播放无需联网。
- 手机及电脑布局，选择后专注展示默写区域。

## 说明及限制

词库来自用户提供的单词表。U3 的单复数错误句已订正。间隔复习使用 5 分钟、30 分钟、12 小时、1/2/4/7/15/30 天的安排，不代表个人遗忘率预测。

错词拼读包含元音标记、音节切分练习及词典音素。单音节词不显示切分线；多音节手动切分不自动判定正误，部分词有参考切分。尚未实现所有单词的完整规则自动切分。

音频使用 edge-tts 的非官方 Edge 在线朗读接口预生成。生成接口的长期可用性不保证；已有音频播放不依赖该接口。生成音频不属于真人录音，未逐条人工听检。词典读音数据使用 CMU Pronouncing Dictionary，许可见 CMUDICT-LICENSE.txt。未为项目整体添加统一开源许可证。

## 已执行验证

JavaScript 语法检查；356 段音频文件完整性检查；浏览器 MP3 解码及播放时间推进；菜单打开后停止朗读及恢复按钮；独立 HTML 播放检查。历史交互检查涵盖逐词错误阻断、订正、删除和提示音。

## 每次默写记录

适用于一个小朋友在同一设备试用，无需账号或邮箱。浏览器 IndexedDB 自动保存每轮默写：开始时间、单元、题量、方向、首次判分的正确率、用时、每题首次填写和正确答案。已完成与未完成的练习都可以在“默写记录”中展开查看。

第一次拼错即记录一次错误，后续重复拼错或订正不会重复计数。跳过单独标记。每题用时按进入题目到首次判分计算（含停留时间，上限 30 分钟）。旧版本只迁移错题及复习计划，不推算历史分数。

当前版本为本机数据库，不跨设备同步；清除浏览器网站数据、使用另一浏览器或无痕模式，会影响记录保留。之前创建的 Supabase 项目未删除，此版本页面不连接该项目，也不会发送邮件。

### 回归验证

安装 Playwright 并启动本地网页后，运行 `node tests/sessions.cjs`。覆盖每轮明细、正确/错误/跳过、完整与中断练习、重复错误只计一次、刷新保存、手机布局以及无邮箱表单。
