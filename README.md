# 单词练习簿

适合五年级及初中学生的中文界面英语默写网站，包含 5A U1–U3 共 158 项单词、短语和句子。

## 启动

在项目目录运行：

```sh
python3 -m http.server 8765
```

浏览器访问 http://localhost:8765/ 。项目是静态网页，无需安装前端依赖。

## 功能

- 单元、练习方式、默写方向和题量选择。
- 逐字母输入；每个单词填完自动批改，拼错后先订正再继续。
- 错误下划线、答题动效、输入及删除提示音。
- 错题本、正确率统计、浏览器本地保存的间隔复习计划。
- Aria 美式神经语音：逐词听读，停顿后完整重读；356 段 MP3 保存在 audio/，播放无需联网。
- 手机及电脑布局，选择后专注展示默写区域。

## 说明及限制

词库来自用户提供的单词表。U3 的单复数错误句已订正。间隔复习使用 5 分钟、30 分钟、12 小时、1/2/4/7/15/30 天的安排，不代表个人遗忘率预测。

错词拼读包含元音标记、音节切分练习及词典音素。单音节词不显示切分线；多音节手动切分不自动判定正误，部分词有参考切分。尚未实现所有单词的完整规则自动切分。

音频使用 edge-tts 的非官方 Edge 在线朗读接口预生成。生成接口的长期可用性不保证；已有音频播放不依赖该接口。生成音频不属于真人录音，未逐条人工听检。词典读音数据使用 CMU Pronouncing Dictionary，许可见 CMUDICT-LICENSE.txt。未为项目整体添加统一开源许可证。
