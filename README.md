# 单词练习簿 · React

面向五年级及初中学生的中文英语默写网站。React 19 + Vite，包含 5A U1–U3 共 158 项单词、短语和句子，356 段本地 Aria 英语音频。

## 开发及构建

需要 Node.js 22.12+（推荐 24）。

```sh
npm ci
npm run dev
```

打开 http://localhost:8765/ 。

```sh
npm test
npm run build
npm run preview
```

`dist/` 是可部署的完整静态网站，包含音频；使用相对资源路径，适合 GitHub Pages 和 App WebView。源码不能直接用 Python 静态服务器运行，构建后的 dist 可以。

## 功能

- 按单元、主题词/页码/时态/语法筛选，随机默写或间隔复习，中英双向，10/20/全部题量。
- 逐字母填写、粘贴、方向键和删除；逐词检查，拼错只显示红色下划线，后续单词锁定，焦点停在末格。
- 答对后停留，显示随机色词性标签、播放完整音频和不阻挡点击的粒子，手动下一题。
- 输入、删除和判题提示音，静音控制；开始及切题自动朗读，重播先停止旧音频。
- 本轮进度、成绩、错题本、间隔复习、每轮历史记录及首次填写明细。
- 小屏、安全区、触摸目标和软键盘视口适配；遵循减少动态效果设置。

## 组件与模块

- `src/components/`：设置/记录弹框、字母格、练习卡、进度统计、错词拼读、粒子、学习抽屉。
- `src/hooks/`：练习流程、学习记录、音频生命周期、WebView 视口管理。
- `src/domain/`：判题、随机队列、复习安排、词性等纯逻辑。
- `src/services/`：IndexedDB 持久化、MP3 播放与提示音；不直接修改界面。
- `src/data/`：词库、音频映射、词性及 CMU 读音。
- `public/audio/`：预生成 MP3；`style.css` 继续沿用原界面样式。

React 管理界面与状态；DOM 操作仅用于焦点、dialog、视口和粒子动画。未将原 app.js 嵌套在 React 外壳内。详见 [架构说明](docs/architecture.md)。

## 数据兼容和限制

沿用 `word-practice-learning` v1 数据库及 `guest` 事件结构，原网站的每轮记录、错题及复习计划可以继续读取。旧 localStorage 数据只迁移错题和复习计划，不推算成绩。首次拼错记一次错误，订正不重复计分；用时从进入题目到首次判分计算，上限 30 分钟。

数据库仍是本机保存，无需登录，不跨设备同步。域名、端口或浏览器改变后会使用另一份存储；清除网站数据会删除记录。原 Supabase 项目仍未删除，本页面不连接它。

间隔为 5 分钟 → 30 分钟 → 12 小时 → 1/2/4/7/15/30 天，不代表个人遗忘率预测。错词切分是手动练习，部分词有参考；未实现完整自动音节规则。词性沿用原词库，未覆盖所有语境。

音频是 edge-tts 预生成的合成 Aria 声音，并非真人录音；生成接口非官方且长期可用性不保证，现有播放不依赖它。读音来自 CMU Pronouncing Dictionary，许可见 CMUDICT-LICENSE.txt。未逐条人工听检。实际 App WebView 的键盘和音频仍需真机验证。

## 回归测试

`npm test` 测试纯逻辑。浏览器回归使用已安装的 Chrome。构建并自动启动测试服务器：

```sh
npm run test:e2e
```

可用 `TEST_URL` 指定预览地址。覆盖答后停留/词性/静音/旧音频停止、粒子点击穿透、每轮记录/刷新持久化/重复错误、旧数据库兼容、范围筛选、错误阻断/订正计分/删除焦点及 320px/横竖屏。

## GitHub Pages

已准备 `.github/workflows/pages.yml`，构建后发布 dist。首次发布 React 版本前，需将仓库 Settings → Pages → Source 从分支发布切换成 **GitHub Actions**。之后推送 main 自动构建发布；直接发布源码目录无法运行 React 页面。
